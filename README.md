# MotoParts — інтернет-магазин мотозапчастин

Готовий сайт: каталог товарів, фільтр по брендах, корзина (зберігається в браузері), оформлення замовлення з оплатою через LiqPay.

## Що вже готово
- Головна сторінка з каталогом і фільтром по брендах
- Корзина (додавання, зміна кількості, видалення)
- Сторінка оформлення замовлення
- Підключення до LiqPay для прийому оплати карткою

## Що потрібно зробити вам (без коду, покроково)

### Крок 1. Розмістити сайт онлайн (безкоштовно, через Vercel)

1. Зареєструйтесь на **https://vercel.com** (можна через Google-акаунт)
2. Зареєструйтесь на **https://github.com** (якщо ще немає акаунту)
3. Створіть новий репозиторій на GitHub і завантажте туди всі файли з цієї папки (на GitHub є кнопка "Add file → Upload files" — можна просто перетягнути всі файли мишкою)
4. У Vercel натисніть **"Add New Project"** → оберіть щойно створений репозиторій → **Deploy**
5. Через хвилину Vercel дасть вам посилання на робочий сайт (наприклад `motoparts-shop.vercel.app`)

### Крок 2. Підключити прийом оплати (LiqPay)

1. Увійдіть у свій кабінет продавця на **https://www.liqpay.ua** (вхід через ваш ФОП/бізнес-акаунт)
2. У розділі **"Мої магазини" → створити магазин** отримаєте два ключі:
   - `Public key`
   - `Private key`
3. У Vercel зайдіть у ваш проєкт → **Settings → Environment Variables**
4. Додайте дві змінні:
   - `LIQPAY_PUBLIC_KEY` = ваш публічний ключ
   - `LIQPAY_PRIVATE_KEY` = ваш приватний ключ
5. Натисніть **Redeploy** (передеплой), щоб зміни набули чинності

Після цього оплата на сайті запрацює по-справжньому.

### Крок 3. Підключити свій домен (наприклад motoparts.com.ua)

1. Купіть домен (наприклад на **https://www.imena.ua** або **https://freehost.com.ua**)
2. У Vercel: Project → Settings → Domains → додайте свій домен
3. Vercel покаже, які записи (DNS) потрібно додати у панелі керування доменом — просто скопіюйте їх туди

## Як додати нові товари

Відкрийте файл `js/products.js` — там простий список товарів. Скопіюйте один блок `{ ... }` і змініть значення (назва, ціна, фото, бренд тощо). Після зміни файлу — завантажте його оновлену версію на GitHub, і Vercel сам оновить сайт за 1-2 хвилини.

## Чого поки що немає (наступні кроки, за потреби)

- **Адмін-панель** для зручного додавання товарів через браузер (зараз редагування — через текстовий файл)
- **Облік замовлень** — зараз оплачені замовлення нікуди не зберігаються автоматично. Найпростіше рішення — підключити сповіщення в Telegram або email при кожній оплаті
- **Розрахунок доставки Нової Пошти** — зараз клієнт просто вписує відділення текстом

Якщо знадобиться будь-який з цих кроків — просто попросіть, і продовжимо звідси.
